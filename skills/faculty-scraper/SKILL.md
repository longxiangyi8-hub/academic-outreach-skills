# Faculty Scraper

从公开的大学院系页面建立可追溯的导师名单，并在不破坏既有人工记录的前提下更新 Excel 或 CSV。

## 开始前

确认或从任务中推断以下信息：

- 目标院系、官网 URL 和纳入的职称范围。
- 输出文件、工作表和更新方式：新建、追加或同步。
- 现有字段映射，以及哪些列属于用户手工维护。
- 是否只收集有招生资格的导师；官网未明确时不要自行判断招生状态。

输入文件存在时，先读取工作表、表头、合并单元格、公式、样式、隐藏行列和已有记录。修改前创建可恢复的副本或写入新文件，除非用户明确要求原位更新。

## 来源与访问边界

优先使用院系 Faculty、Academic Staff 或 People 页面，再用导师官方个人主页补充缺失信息。

- 只采集公开且与学术申请相关的职业信息。
- 尊重网站条款、`robots.txt`、合理访问频率和登录边界。
- 不绕过验证码、付费墙、访问控制或反自动化保护。
- 页面无法访问时，记录失败 URL、时间和缺失字段；改用其他公开官方来源或标记为待人工核验。
- 不用模型记忆补写邮箱、职称、论文或研究方向。

## 收集流程

1. 定位权威的导师列表页并确认分页、筛选器和职称分类。
2. 识别导师卡片或结构化数据。优先使用语义 HTML、JSON-LD 或站点接口；静态页面可用 `requests` 与 BeautifulSoup。正则只用于定位或简单清洗，不作为复杂 HTML 的默认解析器。
3. 提取姓名、邮箱、职位、研究方向、个人主页和列表页来源。只保留页面明确提供的内容。
4. 规范化空白、HTML 实体、相对 URL、邮箱大小写和职位写法，同时保留姓名的官网拼写。
5. 以“学校 + 教师姓名”为主键、官方邮箱为辅助键去重。疑似同名但无法确认时保留两条并标记复核。
6. 将记录与现有表格对比：更新发生变化的官方字段，保留进度、备注和其他人工字段。
7. 写入来源 URL 与核验日期，输出缺失项和异常摘要。

遇到 JavaScript 渲染页面时，可使用浏览器读取已经公开渲染的内容。不要为了自动化方便而扩大采集范围。

## 写入表格

按表头名称识别列，不依赖固定列号。字段定义和兼容规则见 [references/output-schema.md](references/output-schema.md)。

- 目标列不存在时追加到右侧，不移动或覆盖未知列。
- 保留公式、样式、筛选器、冻结窗格、列宽和用户维护的单元格。
- 操作合并单元格前记录其范围；仅在确有必要时解除，并在写入后恢复。
- 对 `.xlsm` 使用保留 VBA 的加载与保存选项。不要把宏工作簿另存为普通 `.xlsx`。
- 追加记录时复制相邻数据行的格式，但不要复制人工状态或备注值。
- 输出到新路径时使用可辨识文件名，并明确说明原文件是否改变。

## 验证

完成后检查：

- 导师数量与官网分页或分类数量是否大致一致，并解释差异。
- 随机抽查至少 5 条或总数的 10%，取较小但不少于 3 条；核对姓名、职位、邮箱、方向和 URL。
- 没有重复主键、明显无效邮箱、占位文本或 HTML 残片。
- 现有进度、备注、公式和其他学校的数据未被覆盖。
- 每条记录都有来源；缺失或冲突字段被明确标记，而非猜测补全。

最后报告新增、更新、未变化、待复核和失败的记录数量，以及输出文件位置。
