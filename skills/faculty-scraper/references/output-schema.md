# 导师名单字段规范

仅在执行表格映射、导入或验证时读取本文件。

## 推荐字段

| 字段 | 类型 | 规则 |
|---|---|---|
| 地区 | 文本 | 国家、地区或城市；同一文件内写法一致 |
| 学校 | 文本 | 官网使用的大学全称 |
| 学院 | 文本 | 学院、系、学部或研究中心名称 |
| 教师 | 文本 | 保留官网显示的姓名拼写 |
| 邮箱 | 文本 | 公开的官方邮箱；移除 `mailto:` 和首尾空格 |
| 职位 | 文本 | 保留官网职称，必要时另建“规范职位”列用于筛选 |
| 方向 | 文本 | 官网明确列出的研究兴趣或简洁归纳；归纳时不得增加新事实 |
| 进度 | 文本 | 用户维护字段，不由抓取流程覆盖 |
| 备注 | 文本 | 用户维护字段，不由抓取流程覆盖 |
| 来源 | URL | 优先个人主页；没有时使用院系列表页 |
| 抓取时间 | 日期 | 使用 `YYYY-MM-DD`，表示最后核验日期 |
| 核验状态 | 枚举 | `已核验`、`部分缺失`、`来源冲突`、`待人工核验` |

## 兼容现有表格

常见同义表头可映射到同一字段：

- `教师`、`导师`、`姓名`、`Faculty`、`Name`
- `方向`、`研究方向`、`Research Interests`
- `职位`、`职称`、`Title`、`Position`
- `来源`、`主页`、`个人主页`、`Profile URL`
- `抓取时间`、`核验日期`、`Last Checked`

映射有歧义时保留原列并新增标准列，不要自行覆盖。

## 去重与更新

1. 主匹配键：规范化后的学校名称 + 教师姓名。
2. 辅助匹配键：官方邮箱或个人主页 URL。
3. 姓名相同但学校、邮箱或主页不一致时，标记人工复核。
4. 官网字段发生变化时可以更新，但 `进度`、`备注` 及未知的人工列必须保留。
5. 官网删除的导师不要直接从用户表格删除；默认标记为“官网未找到”并报告。

## 缺失值

真正缺失时保留空白，并在 `核验状态` 或单独的问题清单中说明。不要使用虚构邮箱、猜测职称或模型记忆填充。
